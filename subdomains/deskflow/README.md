# DeskFlow Help Center — PHP + MySQL

This version is a substantially redesigned help-desk/customer-portal website.

## What is included
- Help-center homepage with knowledge-base search
- Knowledge base categories
- Searchable articles
- Article detail pages and view counts
- Suggested self-service before ticket submission
- Customer support ticket submission
- Ticket number generation
- Ticket lookup by ticket number or email
- Multiple ticket results for an email
- Customer-visible agent replies
- Ticket status and priority
- Separate staff inbox
- Staff ticket detail/conversation view
- Staff status, priority and reply updates
- Knowledge-base article management view
- Automatic database/table creation
- Automatic seed articles
- Automatic default admin creation
- CSRF, prepared statements, password hashing and output escaping

## XAMPP
Extract to `C:\xampp\htdocs\deskflow`, start Apache and MySQL, then open:
`http://localhost/deskflow/`

No SQL import is needed.
