# DisputeDesk

A real-world style dispute/claims case management portal built with PHP + MySQL.

## Features
- Public dispute intake
- Transaction/reference details
- Dispute categories
- Desired resolution
- Evidence summary
- Multi-file evidence upload
- PDF/JPG/PNG validation, 5 MB per file
- Unique case number (DD-XXXXXXXX)
- Public case tracking
- Public case timeline
- Reviewer response
- Admin dashboard
- Search/filter cases
- Priority management
- Status workflow
- Evidence review
- Timeline/public update creation
- Automatic database/table creation
- Automatic default admin creation
- CSRF protection
- Prepared statements
- Password hashing
- No database.sql required

## XAMPP
Extract `disputedesk` into `C:\xampp\htdocs\disputedesk`.
Start Apache and MySQL.
Open `http://localhost/disputedesk/`.

Admin:
`http://localhost/disputedesk/admin/login.php`
Email: `admin@disputedesk.local`
Password: `admin`
